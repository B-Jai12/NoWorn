# NoWorn

> *Don't wear someone else's design. Make your own.*

NoWorn is a custom garment-design platform — give users a blank canvas and the tools to design exactly what they want to wear.

---

## What It Is

A product landing page and waitlist for NoWorn — a fashion-tech startup concept that lets people design their own garments from scratch, with no templates, no compromises.

---

## Features

- **3D Tilt Hero** — Interactive t-shirt hero element with cursor-driven parallax and 3D perspective tilt
- **Waitlist Signup** — Email capture via Formspree with client-side validation
- **Smooth Scrolling** — Section-based navigation with scroll reveal animations
- **Fully Responsive** — Mobile, tablet, and desktop layouts
- **Zero Dependencies** — Pure HTML, CSS, and vanilla JS — no frameworks, no build step

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, animations, grid, flexbox) |
| Logic | Vanilla JavaScript (ES6+) |
| Form Backend | Formspree |
| Fonts | Google Fonts (Instrument Serif, Inter) |
